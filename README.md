# Суфлёр для переписок

Ассистент, который на входящие в Telegram предлагает тебе 3 варианта ответа
через DeepSeek-V3. Отправляешь ответы ты сам — бот собеседникам не пишет.

## Настройка

1. Установи проект в venv (editable-режим, зависимости подтянутся сами):
   `.venv\Scripts\python.exe -m pip install -e ".[dev]"`
2. Получи `api_id` и `api_hash` на https://my.telegram.org → API development tools.
3. Получи ключ DeepSeek на https://platform.deepseek.com.
4. Скопируй `.env.example` в `.env` и заполни `TG_API_ID`, `TG_API_HASH`, `DEEPSEEK_API_KEY`.
5. Скопируй `config.example.yaml` в `config.yaml`. Проще всего оставить
   `panel_chat: me` — подсказки будут приходить в твоё «Избранное» (Saved
   Messages). Если хочешь отдельный чат-пульт — создай приватную группу и
   укажи её **числовой** chat id (у приватных групп нет username, поэтому
   имя не подойдёт).

## Запуск

PowerShell, из корня проекта:

```powershell
.venv\Scripts\python.exe -m suflor.main
```

Или короткой командой `suflor` (ставится вместе с пакетом). Запускать надо
именно из корня проекта: пути к `config.yaml` и `suflor.session` считаются от
текущей директории. Другой конфиг можно задать через `SUFLOR_CONFIG`.

При первом запуске введи номер телефона и код подтверждения из Telegram, а если
включена двухэтапная аутентификация — ещё и облачный пароль. Сессия сохранится в
`suflor.session`, повторный вход не потребуется.

## Как это работает

Бот реагирует только на новые входящие в личных чатах: по уже полученным
сообщениям подсказки задним числом не появятся. На каждое входящее он берёт из
этого диалога последние `context_messages` сообщений (по умолчанию 50, меньше —
если в чате их меньше), отдаёт их DeepSeek и присылает в пульт две вещи:
пересланное исходное сообщение и разбор с вариантами.

```
Переслано от Аня
Привет! Как выходные?

💬 Аня
«Привет! Как выходные?»

📊 Пишет первой и задаёт открытый вопрос — интерес есть,
   можно отвечать свободнее.

1⃣ [игривый] ...
2⃣ [тёплый] ...
3⃣ [с юмором] ...
```

В диалог можно попасть двумя путями: тапом по шапке форварда и по имени в
подсказке — оно кликабельное (ссылка t.me, если есть username, иначе
сущность-упоминание). Оба способа могут не сработать: собеседник вправе
запретить пересылку своих сообщений и скрыть ссылку на аккаунт в форвардах.
Тогда форварда не будет, а имя останется обычным текстом, и рядом с ним
появится числовой id — по нему диалог ищется поиском.

Ответ ты копируешь и отправляешь сам.

## Разбор уже существующего чата

Автоматические подсказки приходят только на новые входящие. Чтобы получить
совет по переписке, которая уже идёт, отправь в пульт `/hint`:

```
/hint @anna
/hint https://t.me/anna
/hint 123456789
```

Либо ответь `/hint` на пересланное в пульт сообщение — это единственный способ
указать собеседника без username.

Ответ такой же, как на входящие. Если последним писал ты и переписка заглохла,
модель предложит, как её оживить, а не «ответит» тебе самому:

```
💬 Аня
«А ты где обычно отдыхаешь?»

📊 Собеседница отвечает коротко и не задаёт встречных вопросов, но тема
   путешествий ей интересна — стоит дать ей раскрыться, а не давить.

1⃣ [игривый] ...
2⃣ [тёплый] ...
3⃣ [с юмором] ...
```

## Управление

- `/on` / `/off` — включить/выключить подсказки. Команды принимаются **только в
  чате-пульте**, в обычных переписках они игнорируются.
- `/hint <@username | ссылка | id>` — разбор существующего диалога.
- Игнор-лист (мама, коллеги) — в `config.yaml`, применяется при старте.
- Состояние `/on` / `/off` сбрасывается во «включено» при перезапуске бота.
