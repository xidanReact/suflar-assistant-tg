# Суфлёр для переписок

Ассистент, который читает твои личные переписки в Telegram и подсказывает, что
ответить: короткий разбор диалога и три варианта следующего сообщения от
DeepSeek. Отправляешь ты сам — бот собеседникам не пишет никогда.

Это не бот из @BotFather, а **юзербот**: он логинится под твоим аккаунтом через
Telethon и видит всё то же, что видишь ты. Подсказки приходят в служебный
чат-пульт — по умолчанию в твоё «Избранное» (Saved Messages).

## Что нужно

- Python 3.10 или новее (в проекте используется `venv` в `.venv`)
- `api_id` и `api_hash` с https://my.telegram.org → API development tools
- Ключ DeepSeek с https://platform.deepseek.com (оплата по токенам)

## Настройка

**1. Установи проект в venv.** Зависимости подтянутся из `pyproject.toml`:

```powershell
.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Editable-режим (`-e`) кладёт в venv ссылку на `src/`, поэтому пакет виден без
возни с `PYTHONPATH`, а правки в коде применяются без переустановки. `[dev]`
добавляет pytest.

**2. Заполни `.env`.** Скопируй `.env.example` в `.env` и впиши три значения:

```
TG_API_ID=1234567
TG_API_HASH=abcdef...
DEEPSEEK_API_KEY=sk-...
```

**3. Заполни `config.yaml`.** Скопируй `config.example.yaml` в `config.yaml`:

```powershell
Copy-Item config.example.yaml config.yaml
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `panel_chat` | `me` | Куда слать подсказки. `me` — «Избранное». |
| `context_messages` | `50` | Сколько последних сообщений диалога отдавать модели. |
| `tones` | четыре тона | Тона вариантов, см. «Настройка вайба». |
| `style` | нейтральный | Манера письма, см. «Настройка вайба». |
| `temperature` | `0.7` | Насколько модель вольничает, 0.3–1.0. |
| `model` | `deepseek-v4-pro` | Модель DeepSeek, см. «Выбор модели». |
| `ignore_usernames` | `[]` | Кому не подсказывать, по username. |
| `ignore_user_ids` | `[]` | То же, по числовому id. |
| `learning` | включено | Самообучение на твоих чатах, см. «Самообучение». |

Про `panel_chat`: проще всего оставить `me`. Если хочешь отдельный чат-пульт,
создай приватную группу и укажи её **числовой** chat id — у приватных групп нет
username, поэтому имя не подойдёт. Username работает только у публичных
каналов и групп.

Про `context_messages`: если в чате сообщений меньше, возьмутся все, что есть.
Из них в промпт попадают только текстовые — медиа и стикеры отбрасываются.
Чем больше число, тем дороже каждый запрос к DeepSeek.

## Настройка вайба

То, как модель пишет, задаётся двумя полями в `config.yaml`. Оба идут прямо в
системный промпт, так что формулируй своими словами.

`tones` — список тонов. **Сколько строк, столько вариантов** и предложит
модель: хочешь два — оставь две строки, хочешь пять — пиши пять. Эти же подписи
попадают в сообщение в пульте, рядом с номером варианта. По умолчанию тонов
четыре: игривый, тёплый, с юмором и спокойный — последний помечен как
рекомендуемый, это безопасный вариант, когда не хочется рисковать.

`style` — общая манера письма: длина, лексика, эмодзи, что нельзя.

```yaml
tones:
  - коротко и сухо
  - с сарказмом

style: |
  Пиши строчными буквами, без смайлов и восклицаний,
  максимум 10 слов в сообщении.
```

С такими настройками вместо трёх развёрнутых вариантов придут два коротких:

```
📊 диалог живой и тёплый, собеседник проявляет интерес
   к твоему путешествию, стоит поддержать тему.

1⃣ [коротко и сухо] обязательно съезди, не пожалеешь.
2⃣ [с сарказмом] ну, теперь у тебя есть повод.
```

Что настройками **не** меняется: структура ответа (сначала разбор, потом
нумерованные варианты) — на неё завязан парсер, поэтому она жёстко зашита в
промпт. Там же зашит потолок флирта: тепло и интерес — да, пошлый подтекст,
двусмысленности и разговоры про тело — нет. Тоном из `tones` его не поднять.
Правки применяются при старте, так что после изменения конфига перезапусти
бота.

### Разбор инициативы

Кто кого вытягивает — сигнал интереса, и модель по сырой переписке считает его
плохо. Поэтому бот считает сам и отдаёт готовым блоком: кто написал первым,
сколько сообщений с каждой стороны, кто чаще нарушает молчание после долгих
пауз и кто писал последним. В разборе это превращается в совет: пишет первой
она — можно отвечать смелее; тяну диалог я, а в ответ односложно — не давить.

Если переписка длиннее `context_messages`, её начало в выборку не попало, и
бот честно говорит модели, что о начавшем судить нельзя, — вместо того чтобы
назвать первым случайного человека из середины диалога.

### Без хождения по кругу

Модель охотно возвращает собеседнику его же вопрос: на «чем занимаешься?»
предлагает ответить «...а ты чем занимаешься?». История у неё перед глазами, но
сама она её на повторы не проверяет. Поэтому вопросы из переписки бот
вытаскивает в отдельный список — с автором и в порядке свежести, повторы
схлопываются:

```
Вопросы, которые уже звучали (свежие внизу):
- я: Как дела?
- Аня: А у тебя?
- Аня: Чем занимаешься?
```

Промпт запрещает задавать их заново и отдельно — отбивать обратно вопрос,
который только что задали тебе. «А ты?» разрешено, только если на этот вопрос
в переписке ещё никто не отвечал.

### Выбор модели

Посмотреть, что доступно на твоём ключе:

```python
OpenAI(api_key=..., base_url="https://api.deepseek.com").models.list()
```

Замер на одном и том же диалоге (пять сообщений, четыре тона):

| Модель | Время | Токенов на ответ | Из них рассуждения |
|---|---|---|---|
| `deepseek-v4-flash` | 36 с | 3427 | 3255 |
| `deepseek-v4-pro` | 13 с | 2051 | 1905 |

Вопреки названиям, **pro быстрее и экономнее по токенам**: flash дольше
буксует во внутренних рассуждениях. По качеству на том же диалоге pro ответил
на заданный вопрос во всех четырёх вариантах, flash — ни в одном из первых
трёх. Поэтому по умолчанию стоит `deepseek-v4-pro`; если варианты кажутся мимо
контекста, смена модели помогает сильнее, чем правка промпта.

Единственное, что говорит в пользу flash, — цена за токен. Сверься с тарифами
на platform.deepseek.com: pro тратит примерно в полтора раза меньше токенов,
так что выигрыш flash в цене может целиком съедаться его многословностью.

Важно: обе модели V4 — **рассуждающие**. Внутренние рассуждения списываются из
того же `max_tokens`, что и ответ, поэтому лимит в коде выставлен с запасом
(6000 плюс 500 на каждый тон). Если урезать его до пары сотен, модель потратит
весь бюджет на размышления и вернёт пустой ответ.

Алиасы `deepseek-chat` и `deepseek-reasoner` ещё работают, но оба ведут на
`deepseek-v4-flash` — лучше указывать модель явно.

### Если варианты не нравятся

**Переигрывает, пишет слишком красиво.** Снижай `temperature` — на `0.4–0.5`
модель заметно сдержаннее. Промпт и так требует одну-две короткие фразы и
запрещает пафос, наигранное остроумие и пикап-заготовки, но температура
перебивает многое.

**Выдумывает то, чего в переписке не было, отвечает мимо вопроса.** Сначала
попробуй `model: deepseek-v4-pro` — на замерах это дало больший эффект, чем
любая правка промпта. Дальше: поднять `context_messages`, снизить
`temperature`.

**Слишком пресно.** Обратная крайность — подними `temperature` к `0.9` и
добавь в `style` что-нибудь про смелость и неожиданные повороты.

### Чувство момента

Вместе с текстом переписки модель получает её тайминг: заметные паузы между
репликами (от часа и больше) и время, прошедшее с последнего сообщения. Ответ
через пять минут и ответ через три дня она строит по-разному — во втором случае
сама предложит вернуться к разговору, не делая вид, что ничего не было.

Тот же диалог, разное время с последнего сообщения:

```
прошло 2 минуты  → Алтай правда особенный. Если соберёшься — могу подсказать,
                   куда лучше поехать в первую очередь.

прошло 3 дня     → Прости, закрутился. Алтай — это правда здорово,
                   если соберёшься — расскажу, куда лучше ехать.
```

## Запуск

Из корня проекта:

```powershell
suflor
```

или, что то же самое, `.venv\Scripts\python.exe -m suflor.main`.

Именно из корня: пути к `config.yaml` и `suflor.session` считаются от текущей
директории. Другой конфиг можно указать переменной `SUFLOR_CONFIG`.

При первом запуске Telethon спросит номер телефона, код подтверждения из
Telegram и — если у тебя включена двухэтапная аутентификация — облачный пароль.
Пустой ввод на шаге пароля не принимается: Telethon трактует пустую строку как
«пароль не передан» и уходит переотправлять код, что заканчивается
непонятной ошибкой. После входа сессия ляжет в `suflor.session`, и заново
логиниться не придётся.

Остановить — Ctrl+C.

## Как это работает

Суфлёр реагирует на новые входящие в реальном времени. Подсказка появится,
только если выполнены **все** условия:

- личный чат (не группа и не канал);
- отправитель — человек, а не бот;
- сообщение входящее, не твоё;
- отправителя нет в игнор-листе;
- суфлёр включён (`/on`).

По уже полученным сообщениям подсказки задним числом не появятся — для этого
есть команда `/hint`, см. ниже.

Когда условия сошлись, бот пересылает исходное сообщение в пульт, вытягивает из
диалога последние `context_messages` сообщений, отдаёт их DeepSeek и присылает
разбор с вариантами:

```
Переслано от Аня
Привет! Как выходные?

💬 Аня
«Привет! Как выходные?»

📊 Пишет первой и задаёт открытый вопрос — интерес есть,
   можно отвечать свободнее.

1⃣ [игривый, с лёгким флиртом] ...
2⃣ [тёплый, искренний] ...
3⃣ [лёгкий, с юмором] ...
4⃣ [спокойный, уместный — рекомендуемый] ...
```

Понравившийся вариант копируешь и отправляешь в чате сам.

### Как попасть в диалог из пульта

Путей два: тап по шапке «Переслано от» и тап по имени в подсказке — оно
кликабельное. Для собеседника с username это ссылка t.me, без username —
сущность-упоминание.

Оба пути могут не сработать, это нормально. Собеседник вправе запретить
пересылку своих сообщений и скрыть ссылку на аккаунт в форвардах. Тогда
форварда не будет, имя останется обычным текстом, а рядом появится числовой
id — по нему диалог находится поиском.

## Разбор уже идущего чата: /hint

Чтобы получить совет по переписке, которая уже началась, отправь в пульт:

```
/hint @anna
/hint anna
/hint https://t.me/anna
/hint t.me/anna
/hint 123456789
```

Для собеседника без username: перешли в пульт любое его сообщение и **ответь**
на этот форвард командой `/hint` без аргументов. Это единственный способ
указать такого человека.

Ответ приходит в том же формате, что и на входящие. Если последним в диалоге
писал ты и переписка заглохла, модель предложит, как её оживить, а не станет
отвечать тебе самому:

```
💬 Аня
«А ты где обычно отдыхаешь?»

📊 Собеседница отвечает коротко и не задаёт встречных вопросов, но тема
   путешествий ей интересна — стоит дать ей раскрыться, а не давить.

1⃣ [игривый, с лёгким флиртом] ...
2⃣ [тёплый, искренний] ...
3⃣ [лёгкий, с юмором] ...
4⃣ [спокойный, уместный — рекомендуемый] ...
```

## Управление

| Команда | Что делает |
|---|---|
| `/on` | Включить подсказки |
| `/off` | Выключить подсказки |
| `/hint <@username \| ссылка \| id>` | Разобрать существующий диалог |
| `/hint` в ответ на форвард | То же для собеседника без username |
| `/train [@username]` | Собрать корпус моей манеры из истории переписок |
| `/stats` | Что бот выучил: размер корпуса, выбранные тона, средняя оценка |
| `/learn on` / `/learn off` | Копить данные для самообучения или нет |
| `/forget @username` | Стереть из базы всё, что собрано по этому человеку |

## Самообучение

Бот запоминает, что из предложенного ты отправил, что написал вместо этого сам
и как на это ответила собеседница, — и подмешивает твою манеру в промпт. Это не
дообучение весов модели: веса DeepSeek не трогаются, всё происходит через
подбор образцов и статистику в промпте.

Что копится в `suflor.db` (файл рядом с сессией, в git не попадает):

- **выданные подсказки** — тона и варианты;
- **отправленное тобой** с пометкой, откуда оно: взял вариант как есть,
  поправил его или написал своё;
- **исход** — ответила ли она, как быстро, насколько длинно, был ли встречный
  вопрос.

В образцы твоей манеры идут **только** свои тексты и правки. Принятый без
изменений вариант писала модель, и учить её на нём — замыкать её на саму себя:
через месяц все подсказки стали бы одинаковыми.

Пока своих сообщений меньше `min_samples`, промпт собирается ровно как раньше.
Чтобы не ждать неделями, есть `/train` — он проходит по последним личным
диалогам и собирает твои сообщения из уже существующей переписки. Игнор-лист
при этом уважается: переписка с мамой — тоже твой текст, но другого регистра.

Что получается в промпте:

```
Вот как я пишу сам — держись этой манеры, она важнее общих правил о стиле:
- «норм, отдыхаю. кофе пью на балконе»
- «сегодня никак, давай в четверг»
Чаще всего я беру вариант в тоне «лёгкий, с юмором» (11 из 18).
Когда правлю предложенное: предложенное я обычно сокращаю примерно на 30%,
смайлов ставлю меньше, чем в предложенном.
```

### Про приватность

База хранит тексты переписок **открытым текстом**. Она в `.gitignore`, но не
зашифрована: у кого есть доступ к файлам на машине, тот их прочитает. Если это
не подходит — `learning.enabled: false` в конфиге или `/learn off`. Стереть
собранное по конкретному человеку: `/forget @username`.

Все команды принимаются **только в чате-пульте** — в обычных переписках они
игнорируются и собеседник ничего не увидит.

Состояние `/on` / `/off` живёт в памяти процесса и при перезапуске сбрасывается
во «включено». Весь `config.yaml` — игнор-лист, тона, стиль — читается один раз
на старте: поправил конфиг, перезапусти бота.

## Сколько это стоит

Каждое входящее сообщение — один запрос к DeepSeek. Написали пять сообщений
подряд — получишь пять подсказок и пять оплаченных запросов. Основную часть
стоимости даёт контекст, так что если счёт кажется большим, уменьшай
`context_messages`.

## Если что-то пошло не так

**`ModuleNotFoundError: No module named 'suflor'`** — пакет не установлен в
venv. Выполни `pip install -e .` из корня проекта.

**`FileNotFoundError: config.yaml`** — либо не скопировал `config.example.yaml`,
либо запускаешь не из корня проекта.

**`TypeError: Client.__init__() got an unexpected keyword argument 'proxies'`** —
несовместимость `openai` со свежим `httpx`. Обнови зависимости:
`pip install -e . --upgrade`.

**`SendCodeUnavailableError` при первом входе** — ты нажал Enter на шаге
облачного пароля, Telethon принял это за «пароля нет» и попытался переслать
код, а Telegram исчерпал способы доставки. Подожди несколько минут и войди
заново, введя пароль от двухэтапной аутентификации. Забыл его — сбрось в
Telegram → Настройки → Конфиденциальность → Двухэтапная аутентификация.

**«Не нашёл диалог»** в ответ на `/hint` — Telethon не смог определить
собеседника по тому, что ты прислал. Проверь username или воспользуйся
форвардом.

**Подсказки не приходят вообще** — проверь, что не отправлял `/off`, что чат
личный, что собеседник не бот и не в игнор-листе, и что в консоли не висит
трейсбек.

## Разработка

```powershell
.venv\Scripts\python.exe -m pytest
```

Структура:


| Файл | Ответственность |
|---|---|
| `src/suflor/main.py` | Точка входа, Telethon-клиент, обработчик событий, команды |
| `src/suflor/config.py` | Чтение `config.yaml` |
| `src/suflor/chat_filter.py` | Решение, подсказывать ли на это сообщение |
| `src/suflor/suggester.py` | Промпт, вызов DeepSeek, разбор ответа модели |
| `src/suflor/control_panel.py` | Форматирование сообщения для пульта |

Тесты покрывают чистые функции: фильтр чатов, конфиг, парсинг ответа модели,
форматирование, разбор целей `/hint`, подсчёт UTF-16 офсетов для кликабельного
имени. Всё, что требует живого Telegram, тестируется заглушками.
