# Дизайн: Ассистент-суфлёр для переписок (Дайвинчик / Telegram)

**Дата:** 2026-07-23
**Статус:** утверждён, готов к планированию реализации

## Суть

Userbot на *собственном* Telegram-аккаунте пользователя читает входящие сообщения
из личных чатов. На каждое новое сообщение от человека генерирует через DeepSeek-V3
три варианта ответа (разными тонами) и присылает их пользователю в служебный
чат-пульт. Пользователь выбирает/правит и отправляет ответ **сам**. Бот **никогда
не отправляет сообщения собеседникам автоматически** — это суфлёр, а не автоответчик.

Это ключевое этическое ограничение архитектуры: инструмент помогает пользователю
писать быстрее и с идеями, но собеседник всегда общается с живым человеком.

## Компоненты

Каждый компонент — отдельный модуль с одной чёткой ответственностью.

1. **`tg_listener`** (Telethon) — вход в аккаунт пользователя, ловит новые входящие
   из приватных чатов (не группы/каналы/боты), достаёт последние N сообщений
   диалога как контекст.
2. **`suggester`** (OpenAI-совместимый клиент → DeepSeek API) — принимает историю
   диалога, возвращает 3 варианта ответа разными тонами:
   игривый/флиртующий, тёплый/искренний, лёгкий с юмором.
3. **`control_panel`** — форматирует и отправляет варианты в отдельный служебный
   чат-пульт (отдельная приватная группа «только я», удобнее «Избранного» —
   не смешивается с личными заметками пользователя).
4. **`config`** — `.env` (ключи API, telegram `api_id`/`api_hash`) +
   `config.yaml` (стиль, N сообщений контекста, ignore-list).
5. **`main`** — связывает компоненты, хранит состояние (вкл/выкл).

## Отбор чатов

Реагируем на любые входящие из приватных чатов с людьми. Предохранители, чтобы
не спамить на близких/коллегах:

- **`/on` и `/off`** в чат-пульте — глобально включить/выключить суфлёра.
- **ignore-list** в `config.yaml` — id/username, для кого не предлагать ответы.
- Реагируем только на **входящие** (не на сообщения самого пользователя).
- Реагируем только на **личку с людьми** — боты, группы, каналы игнорируются.

## Поток данных

```
Новое входящее
  → tg_listener собирает последние ~10 сообщений диалога
  → suggester шлёт в DeepSeek с промптом
    «помоги ответить, вот переписка, дай 3 варианта разными тонами»
  → control_panel присылает в чат-пульт:

    💬 Аня: «а ты чем по выходным занимаешься?»
    1️⃣ [игривый] ...
    2️⃣ [тёплый] ...
    3️⃣ [с юмором] ...

  → пользователь копирует нужный вариант, правит, отправляет сам
```

## Обработка ошибок

- DeepSeek недоступен / лимит → одно сообщение в пульт
  «не смог сгенерировать, попробуй позже», без падения процесса.
- Telegram отключился → авто-reconnect (штатная возможность Telethon).
- Первый запуск → интерактивный вход по коду из Telegram; сессия сохраняется
  в файл, повторный вход не требуется.

## Тестирование

- `suggester` — тест на мок-ответе API (корректный парсинг 3 вариантов,
  обработка ошибки API).
- Логика фильтра чатов (человек/бот/группа, on/off, ignore-list) — юнит-тесты
  на чистой логике, без реального Telegram.

## Стек

Python 3.13, `telethon`, `openai` (клиент для DeepSeek через `base_url`),
`pyyaml`, `python-dotenv`, `pytest`.

## Явно вне рамок (YAGNI)

- Никакой автоотправки ответов собеседникам.
- Никакого автолайкинга/массовых действий.
- Никакой работы с Twinby (нет публичного API; вне задачи).
- Никакого OCR/скриншотов — работаем напрямую с Telegram-аккаунтом.
